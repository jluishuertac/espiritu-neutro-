# Espíritu Neutro

Aplicación móvil construida con React Native + Expo para ayudar a personas a desarrollar hábitos saludables mediante consistencia, retos privados y apoyo social.

## Estado actual

Paso 1 de implementación:

- Estructura base del proyecto Expo.
- TypeScript configurado.
- Navegación con React Navigation.
- Welcome Screen.
- Login Screen.
- Onboarding de objetivo, barrera, nivel, selección de hábitos y confirmación de reto.

No incluye todavía IA, grupos, rankings, notificaciones ni wearables.

## Requisitos

- Node.js LTS.
- npm.
- Expo CLI mediante `npx expo`.

## Instalación

```bash
npm install
```

## Ejecutar

```bash
npm start
```

Luego abre la app en Expo Go, simulador iOS, emulador Android o web.

## Validación TypeScript

```bash
npm run typecheck
```
